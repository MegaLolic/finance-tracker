# Постоянный адрес для локального приложения

Бесплатный аккаунт ngrok получает назначенный dev-домен. Этот адрес сохраняется
при перезапусках агента; собственное имя бесплатный тариф не позволяет выбрать.
У бесплатного тарифа есть квоты и предупреждение перед открытием сайта.

1. Создай аккаунт на https://dashboard.ngrok.com/signup и выполни его требования
   подтверждения. Покупка домена для назначенного dev-домена не требуется.
2. Открой https://dashboard.ngrok.com/get-started/your-authtoken и скопируй токен.
3. В PowerShell из корня проекта запусти `./scripts/share.ps1 set-token` и вставь
   токен в скрытый запрос. Не отправляй токен в чат и не сохраняй его в Git.
4. Убедись, что Docker, Java-сервисы и frontend на порту 4173 работают.
5. Запусти `./scripts/share.ps1 start`. Скрипт выведет публичную HTTPS-ссылку.

`./scripts/share.ps1 status` повторно показывает адрес.
`./scripts/share.ps1 stop` останавливает туннель.

Токен хранится в `.env.ngrok`, исключённом существующим правилом `.env.*`.
Это локальный текстовый файл с секретом: он также виден владельцу Docker через
настройки контейнера. Не делись этим файлом, выводом Compose config и Docker inspect.
При утечке отзови токен в аккаунте ngrok.

Контейнер публикует только frontend: хостовые порты для туннеля и его инспектора
не открываются, захват HTTP-запросов отключён. `unless-stopped` восстанавливает
запущенный туннель после рестарта Docker; после явного stop используй start.
После перезагрузки компьютера Java-приложения и frontend нужно запустить снова.
Постоянный адрес не означает доступность при выключенном компьютере.

Cloudflare Quick Tunnel остаётся отдельным контейнером `finance-assistance-share`.
После успешной проверки ngrok его можно остановить:
`docker stop finance-assistance-share`.

Документация: [назначенный dev-домен](https://ngrok.com/docs/gateway/domains),
[Docker](https://ngrok.com/download/docker),
[ограничения бесплатного тарифа](https://ngrok.com/docs/pricing-limits/free-plan-limits).
